# Copilot Education Platform - демо платформы для идеатона

Учебная платформа, которая делает ИИ-копилота обязательной и удобной частью учёбы.
Преподаватель создаёт урок за пару минут, студент проходит его с ИИ-ассистентом, а платформа сама собирает недочёты урока, формирует Word-отчёт, Excel с оценками и месячный рейтинг.

## Как запустить

1. Установи Node.js (версия LTS) с nodejs.org. Проверка: `node -v`
2. Открой терминал в папке проекта и выполни:
   ```
   npm install
   ```
3. Скопируй файл `.env.example` в `.env`:
   - Windows: `copy .env.example .env`
   - Mac/Linux: `cp .env.example .env`
4. Запусти сервер:
   ```
   npm start
   ```
5. Открой в браузере http://localhost:3000

## Режим ИИ

В файле `.env`:

| Переменная | Значение |
|---|---|
| `MOCK_AI=true` | Демо-режим: заготовленные ответы, интернет и ключ не нужны (безопасно для защиты) |
| `MOCK_AI=false` | Настоящий ИИ. Нужен `GEMINI_API_KEY` (бесплатный ключ: https://aistudio.google.com/apikey), модель в `GEMINI_MODEL` (по умолчанию gemini-3.8-flash) |
| `AI_PROVIDER` | `gemini` (по умолчанию) или `openai` (тогда нужны `OPENAI_API_KEY`, `OPENAI_MODEL`) |

Режим можно переключить прямо на сайте, без перезапуска: значок аватара справа сверху - Настройки - "Демо-режим ИИ".
Если ИИ недоступен (нет интернета, ошибка ключа), платформа сама переключается на запасной режим и показывает уведомление.

В демо-режиме уроки и ответы ассистента на русском. Настоящий ИИ создаёт урок на выбранном языке (русский или казахский).

## Демо-сценарий для питча (3 минуты)

1. **Преподаватель:** Главная - "Создать урок с ИИ" - тема "Циклы в Python" - "Сгенерировать" - "Опубликовать".
2. **Студент:** переключатель сверху - Студент - Уроки - открыть урок. Пройти 2 шага, в чате справа написать "Не понял, что такое break": ассистент подскажет и передаст заметку преподавателю.
3. **Преподаватель:** Уроки - открыть урок "Циклы в Python": виден список недочётов, которые собрал ассистент. Скачать **Word** (отчёт), **JSON** (недочёты).
4. Скачать **Excel** с оценками.
5. **Рейтинг:** пьедестал топ-3 и призы.

Сброс демо-данных к исходному состоянию: Настройки - "Сбросить" или горячая клавиша **Ctrl + Alt + R**.

## Конспекты и логотип Copilot

- У каждого урока есть **письменный конспект** (разделы с тезисами, термины, пример). ИИ готовит его вместе с уроком, преподаватель выбирает объём (коротко или подробно) и может отредактировать перед публикацией.
- Студент сначала читает конспект, потом нажимает «Начать вопросы». Конспект можно скачать в Word (`/api/lessons/ID/notes.docx`).
- Логотип Copilot: положи официальный файл в `public/img/copilot.svg` (или `copilot.png`), он появится у помощника справа. Пока файла нет, показывается обычный значок.

## Адаптивность (телефон, планшет, ноутбук)

- **Ноутбук и монитор:** три колонки (меню, содержимое, помощник Copilot). На больших экранах колонки шире.
- **Планшет и телефон (меньше 1180 px):** меню уходит вниз экрана как в мобильном приложении, помощник Copilot открывается круглой кнопкой в правом нижнем углу и выезжает снизу.
- Подиум рейтинга, таблицы, конспект, прохождение урока и все формы подстроены под узкий экран, поля ввода не увеличивают масштаб на iPhone, учтены вырезы экрана и поворот телефона.

## Анимации и дизайн

Новый стиль "Северное сияние + бенто": стеклянные карточки с размытием, живой градиентный фон, неоновые акценты. Есть **тёмная и светлая тема** (кнопка солнца/луны сверху, выбор запоминается). Шрифты Onest и Inter лежат локально.
Новые эффекты: заголовки появляются по словам, фон слегка двигается за курсором, подсветка внутри карточек следует за курсором, "магнитные" главные кнопки, блик на кнопках, анимированный градиент в заголовках.

Библиотеки лежат в `public/vendor`, поэтому всё работает **без интернета**: GSAP (анимации), canvas-confetti (конфетти), шрифты Onest и Inter (с кириллицей и казахскими буквами).

Что анимировано:
- **Главная:** плавное появление блоков, числа "набегают" от нуля, кольцо и полоски прогресса дорисовываются, плавающая книга и подсказки в hero, подсветка за курсором.
- **Меню и роли:** индикатор плавно переезжает на выбранный пункт и на выбранную роль.
- **Урок:** переход между шагами, дрожание поля при ошибке, конфетти за верный ответ, большой салют на итоговом экране.
- **Чат-ассистент:** ответ "печатается", заметка для преподавателя появляется после ответа.
- **Рейтинг:** подиум собирается по очереди (постаменты, падающие карточки, корона, конфетти), строки таблицы въезжают.
- **Создание урока:** экран "ИИ думает" со сменой статусов, затем шаги урока появляются по очереди.
- **Мелочи:** наклон карточек под курсором, волна на кнопках, колокольчик, скелетон при загрузке.

Правила, которых придерживается дизайн (по скиллу UI UX Pro Max): анимация объясняет действие, а не просто украшает; текст проходит проверку контраста 4.5:1; видна рамка фокуса при работе с клавиатуры; если в системе включено "уменьшить движение", анимации отключаются.

Код анимаций: `public/js/fx.js` и `public/css/fx.css`. Если нужно что-то отключить, достаточно убрать вызов `fx('...')` в `public/js/app.js`.

## Структура проекта

```
server.js          сервер и все маршруты API
server/db.js       чтение и запись JSON-файлов
server/ai.js       работа с Gemini (и OpenAI) и запасной режим
server/mock.js     заготовленные уроки и ответы (MOCK_AI)
server/rating.js   формула рейтинга
server/reports.js  Word-отчёт и Excel
server/seed.js     тестовые данные
public/            сайт: index.html, css/ (style.css, fx.css), js/ (app.js, fx.js), i18n/, vendor/ (GSAP, confetti, шрифт)
data/              данные в JSON (users, courses, lessons, attempts, gaps, activity)
docs/mockup.png    макет дизайна (положи сюда свой файл)
```

## Формула рейтинга

Баллы = средняя оценка за месяц x 0,7 + активность x 0,3.
Активность = min(100, пройденные уроки за месяц / 5 x 100). Повторное прохождение одного урока баллы не увеличивает.
Оценка за урок = среднее по вопросам, за каждую лишнюю попытку на вопрос минус 10 баллов.
