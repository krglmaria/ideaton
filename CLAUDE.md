# Контекст проекта

Демо-платформа для идеатона (партнёр - Microsoft). Колледжи покупают лицензии Microsoft Copilot, а им не пользуются. Наша платформа делает ИИ-помощника обязательной и удобной частью учёбы.

**Роли:** преподаватель и студент (переключатель сверху).

**Функции:**
- преподаватель генерирует урок по теме и целям
- студент проходит урок, справа чат с ИИ-ассистентом, который подсказывает, но не даёт готовый ответ
- ассистент собирает недоработки урока в data/gaps.json
- у урока есть конспект (lesson.notes: sections, terms, example): его даёт преподаватель (ИИ готовит), студент читает перед вопросами, есть выгрузка в Word
- по уроку формируется Word-отчёт для преподавателя
- оценки выгружаются в Excel
- есть ежемесячный рейтинг студентов

**Разделы:** Главная, Уроки, Курсы, Рейтинг.

**Стек:** HTML/CSS/vanilla JS (public/), Node.js + Express (server.js, server/), данные в JSON-файлах в data/, ИИ Gemini через HTTP (запасной вариант openai), пакеты docx, exceljs.

**Правила:**
- ключ API только в .env на сервере (GEMINI_API_KEY, модель GEMINI_MODEL); провайдер в AI_PROVIDER
- режим MOCK_AI=true отдаёт заготовленные ответы без обращения к API
- интерфейс на русском и казахском (переключатель, тексты в public/i18n)
- код простой, с короткими комментариями на русском, так как автор учится
- не усложняй архитектуру
- в текстах использовать обычный дефис "-", а не длинное тире

**Дизайн:** "Северное сияние + бенто": стеклянные карточки, анимированный градиентный фон (.aurora), тёмная тема по умолчанию и светлая (кнопка в верхней панели, html[data-theme], цвета в переменных style.css). Шрифты Onest (заголовки) и Inter (текст), оба локально. Раскладка: левое меню, центр, справа панель ИИ-копилота. Макет docs/mockup.png больше не основа.

**Формула рейтинга:** баллы = средняя оценка за месяц x 0,7 + активность x 0,3; активность = min(100, пройденные уроки за месяц / 5 x 100).

**Запуск:** npm start, сайт на http://localhost:3000. Сброс демо-данных: кнопка в интерфейсе или POST /api/reset.

**Анимации:** GSAP и canvas-confetti лежат локально в public/vendor (работает без интернета). Все эффекты в public/js/fx.js и public/css/fx.css, вызываются из app.js через fx('имя'). Обязательно уважать prefers-reduced-motion. Шрифт Inter локально.
